# Pigmenta Tintas

Projeto web demonstrativo de uma loja de tintas, desenvolvido com foco em apresentação de produtos, experiência do usuário e organização visual.

## Funcionalidades

- Layout responsivo para computador, tablet e celular;
- Menu adaptado para dispositivos móveis;
- Destaque principal com interação de cores;
- Área de simulação e seleção de cores;
- Exibição de categorias;
- Catálogo de produtos com filtros;
- Lista de orçamento;
- Calculadora estimativa de quantidade de tinta;
- Perguntas frequentes;
- Área de contato e rodapé informativo.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Personalização

O projeto pode ser adaptado com:

- identidade visual própria;
- produtos reais;
- imagens da loja;
- informações comerciais;
- canais de contato;
- dados técnicos dos produtos;
- integração com WhatsApp ou formulário de atendimento.

## Sobre o projeto

Este projeto foi desenvolvido como uma base original para estudo, portfólio e demonstração de uma loja virtual de tintas, utilizando referências de design comuns em sites comerciais modernos.

A identidade visual, imagens, textos e conteúdos finais devem ser personalizados de acordo com o projeto em que a aplicação será utilizada.
