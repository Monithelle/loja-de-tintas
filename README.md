# Pigmenta Tintas — projeto base

Projeto demonstrativo de uma loja de tintas, criado para servir como base de portfólio.

## Estrutura

```text
loja_tintas_base/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    └── img/
        ├── lata-azul.svg
        ├── lata-verde.svg
        ├── lata-laranja.svg
        └── lata-cinza.svg
```

## Funcionalidades incluídas

- Layout responsivo.
- Menu mobile.
- Hero com paleta de cores interativa.
- Estúdio de cores com seletor e código hexadecimal.
- Categorias.
- Produtos com filtros.
- Lista demonstrativa de orçamento.
- Calculadora simples de quantidade de tinta.
- FAQ.
- CTA e rodapé.

## Antes de publicar

Substitua:

- nome "Pigmenta" pelo nome real da loja/projeto;
- telefone, e-mail e cidade;
- produtos fictícios por produtos reais;
- ilustrações SVG pelas imagens reais;
- botão de contato por WhatsApp ou formulário real;
- rendimento da calculadora pelos dados do produto escolhido.

## Observação

Este projeto foi criado como uma base original inspirada em padrões modernos de sites de lojas de tintas. Não reutilize logotipos, fotografias, textos comerciais ou identidade visual de terceiros sem autorização.
